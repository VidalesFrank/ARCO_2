Descripción del Módulo

El módulo de Escaleras calcula y verifica las deflexiones de escaleras de concreto reforzado modeladas como losas inclinadas de un tramo o de dos tramos (peldaños + descanso). El cálculo sigue el método de inercia efectiva de Branson (NSR-10 C.9.5.2) para determinar la deflexión inmediata y el efecto de largo plazo.

El módulo no requiere importación de ETABS. Todos los datos se ingresan directamente por el usuario.

Modelo Estructural

La escalera se modela como una viga simplemente apoyada (o con continuidad) con dos segmentos de carga uniforme:

  • Tramo de peldaños (L1): carga uniforme wu1 correspondiente al peso de los peldaños, acabados y carga viva.
  • Tramo de descanso (L2): carga uniforme wu2 correspondiente al peso de la losa plana de descanso, acabados y carga viva.

Para la deflexión, ARCO calcula una carga equivalente ponderada por longitud para simplificar el cálculo al de una viga con carga uniforme equivalente sobre la longitud total L = L1 + L2.

Cuándo se Requiere Doble Capa

Si el espesor de la losa h ≥ 20 cm, ARCO activa automáticamente la opción de doble capa de refuerzo. En este caso:

  • Capa inferior: As_flex (refuerzo de flexión calculado) + As_retracción/2
  • Capa superior: As_retracción/2 (para control de fisuración en la cara comprimida)

La cuantía de retracción es ρ_ret = 0.0018 para fy ≥ 420 MPa, o ρ_ret = 0.0020 para fy < 420 MPa.

Criterio de Cumplimiento

La escalera cumple cuando:

  • Deflexión inmediata: δ_inm ≤ L/360 (NSR-10 Tabla C.9.5(b), para elementos no estructurales susceptibles al daño)
  • Deflexión de largo plazo: δ_LP ≤ L/480 (con elementos no estructurales apoyados en la escalera)
Si la escalera no tiene elementos no estructurales susceptibles al daño (tabiques, rellenos, etc.) sobre ella, se puede usar el límite más permisivo L/240 para la deflexión de largo plazo. Sin embargo, ARCO verifica por defecto contra L/480 por ser el criterio más conservador.

Corrección por Inclinación

La carga uniforme wu1 en el tramo de peldaños debe ser ingresada en proyección horizontal (kN/m de proyección). El usuario debe haber convertido previamente el peso de la losa inclinada a su componente horizontal multiplicando por:

  • Factor = 1/cos(α), donde α es el ángulo de inclinación de la escalera

ARCO no realiza esta conversión automáticamente, ya que el usuario puede tener diferentes criterios para la inclinación de cada tramo.
