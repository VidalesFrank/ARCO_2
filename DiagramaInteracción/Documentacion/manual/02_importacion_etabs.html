Exportación desde ETABS

ARCO lee los resultados de ETABS desde un archivo Excel. El proceso de exportación en ETABS varía según la versión, pero en general sigue estos pasos:

1
Ejecutar el análisis — Verifique que el análisis esté completo y sin errores en ETABS antes de exportar.
2
Ir a File → Export → Save Tables to Excel — En ETABS, acceda al menú File (o Display en versiones antiguas) y seleccione la opción de exportar tablas a Excel.
3
Seleccionar las tablas requeridas — Marque todas las hojas que necesita ARCO según los módulos que va a usar. Consulte la tabla de hojas requeridas más adelante.
4
Guardar el archivo Excel — Asegúrese de guardarlo en formato .xlsx compatible con Excel 2010 o superior.
ARCO soporta tanto el formato E17 (ETABS versiones anteriores a 2016) como E23 (ETABS 2016 y posteriores). La detección es automática — no necesita indicarle al programa qué versión está usando.

Cómo Importar en ARCO

Cada módulo de ARCO tiene su propio proceso de importación. El flujo general es:

1
Abrir el módulo — Haga clic en el botón del módulo en la pantalla principal (Pilas, Columnas, Muros, Vigas, etc.).
2
Hacer clic en "Importar" o "Cargar ETABS" — Cada módulo tiene un botón dedicado para la importación. En algunos módulos está en la pestaña de Importación.
3
Seleccionar el archivo Excel — Se abre un diálogo para seleccionar el archivo .xls o .xlsx exportado de ETABS.
4
Esperar la carga — ARCO lee todas las hojas necesarias. Para proyectos grandes (muchos pisos y elementos) esto puede tomar unos segundos.
5
Confirmar la importación — ARCO mostrará un mensaje confirmando cuántos elementos fueron importados. En caso de error, se mostrará el detalle del problema.

Troubleshooting: Problemas Comunes al Importar

ARCO no encuentra las hojas requeridas

Si ARCO no puede leer el archivo, verifique que el archivo Excel tenga las hojas con los nombres exactos indicados en la tabla anterior. Los nombres distinguen entre mayúsculas y minúsculas en algunas versiones de ETABS.
  • Abra el archivo Excel manualmente y verifique los nombres de las pestañas.
  • Compare contra la tabla de hojas requeridas. Un espacio o guion diferente puede causar el error.
  • Si usa ETABS E23 pero el archivo tiene nombres E17 (o viceversa), ARCO fallará en la detección. En este caso, exporte nuevamente desde ETABS.

El archivo Excel tiene datos vacíos o incompletos

  • Asegúrese de que ETABS haya ejecutado el análisis exitosamente antes de exportar.
  • Verifique que las combinaciones de carga sean de tipo "Combination" y no solo casos de carga individuales.
  • Para fuerzas en vigas, asegúrese de que la opción "Output Stations" esté configurada para generar estaciones intermedias (mínimo 5 por frame).

Error de conexión OLE DB al leer el Excel

  • El driver de Microsoft Access Database Engine debe estar instalado. Descárguelo desde Microsoft si no está disponible.
  • Asegúrese de que el archivo no esté abierto en Excel mientras ARCO intenta leerlo.
  • Si el archivo es .xlsx y hay problemas, intente guardarlo como .xls desde Excel.

Combinaciones de Diseño

Después de importar, cada módulo requiere que el usuario seleccione qué combinaciones se usarán para el diseño. Este paso es obligatorio antes de calcular.

Las combinaciones de diseño para vigas, columnas y muros se seleccionan de forma independiente en cada módulo. Un cambio en las combinaciones de columnas no afecta las de muros.

Las combinaciones típicas de diseño para concreto reforzado según NSR-10 son:

  • 1.4D (carga muerta amplificada)
  • 1.2D + 1.6L (gravitacional dominante)
  • 1.2D + 1.0L ± 1.0Ex (sismo en X)
  • 1.2D + 1.0L ± 1.0Ey (sismo en Y)
  • 0.9D ± 1.0Ex (sismo con mínima carga muerta)
  • 0.9D ± 1.0Ey
