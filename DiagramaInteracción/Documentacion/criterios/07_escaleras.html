1. Peralte Efectivo y Parámetros del Material

d = h - recubrimiento - Ø_barra/2 [m] Módulo de elasticidad del concreto: Ec = 4700 · √fc [MPa] → Ec_kN = Ec · 1000 [kN/m²] Módulo de rotura (resistencia a tracción): fr = 0.62 · √fc [MPa] → fr_kN = fr · 1000 [kN/m²] (fc en MPa)

2. Inercia Bruta

Ig = b · h³ / 12 [m⁴] yt = h / 2 [m] (distancia del centroide a la fibra más traccionada)

3. Momento de Fisuramiento

NSR-10 C.9.5.2.3
Mcr = fr_kN · Ig / yt [kN·m]

4. Inercia Agrietada (Sección Fisurada)

4.1 Posición del eje neutro en sección fisurada

Relación modular: n = Es / Ec = 200000 / Ec (adimensional, Es en MPa, Ec en MPa) Ecuación de equilibrio de momentos estáticos sobre el eje neutro: b·c²/2 = n·As·(d - c) Resolviendo la cuadrática: c = [-n·As + √((n·As)² + 2·b·n·As·d)] / b [m]

4.2 Inercia de la sección fisurada

Icr = b·c³/3 + n·As·(d - c)² [m⁴]

5. Inercia Efectiva de Branson

NSR-10 C.9.5.2.3
Ma = momento actuante de servicio [kN·m] Si Ma ≤ 0 o Ma = 0 → Ie = Ig (sección no fisurada) Si Ma > 0: ratio = Mcr / Ma Ie = ratio³ · Ig + (1 - ratio³) · Icr [m⁴] Restricción: Ie = min(Ie, Ig) (la inercia efectiva nunca supera la bruta)

6. Deflexión Inmediata

6.1 Carga equivalente de servicio

La carga de servicio total se pondera por longitud de tramo: w_eq = (w_serv1·L1 + w_serv2·L2) / (L1 + L2) [kN/m] Donde: w_serv1 = wu1 / factor_amplificación (carga de servicio del tramo 1) w_serv2 = wu2 / factor_amplificación (carga de servicio del tramo 2) L = L1 + L2 (longitud total)

6.2 Deflexión inmediata por carga distribuida

δ_inm = (5/384) · w_eq · L⁴ / (Ec_kN · Ie) [m] → × 1000 = [mm] (w_eq en kN/m, L en m, Ec_kN en kN/m², Ie en m⁴)
Este cálculo asume un vano simplemente apoyado. Si la escalera tiene continuidad en los extremos, la deflexión real será menor. ARCO usa apoyo simple como hipótesis conservadora.

7. Deflexión de Largo Plazo

NSR-10 C.9.5.2.5
λ = 2.0 (factor de fluencia para elemento sin refuerzo de compresión significativo) Si As_sup > 0: ρ' = As_sup / (b · d) λ = 2.0 / (1 + 50·ρ') (reducción por refuerzo de compresión) δ_LP = δ_inm · λ [mm] La deflexión de largo plazo representa los efectos de fluencia y retracción del concreto a lo largo de la vida útil del elemento.

8. Límites de Deflexión

NSR-10 Tabla C.9.5(b)
Deflexión inmediata: δ_inm ≤ L/360 [mm] (Elementos que soportan o están unidas a elementos no estructurales susceptibles de dañarse por deflexiones grandes) Deflexión de largo plazo (diferida + inmediata de cargas sostenidas): Si hay elementos susceptibles al daño: δ_LP ≤ L/480 [mm] Si no hay elementos susceptibles: δ_LP ≤ L/240 [mm]

9. Refuerzo de Retracción y Doble Capa

NSR-10 C.7.12.2
Cuantía de retracción y temperatura: ρ_ret = 0.0018 si fy ≥ 420 MPa ρ_ret = 0.0020 si fy < 420 MPa As_retracción = ρ_ret · b · h [mm²] (por metro de ancho, h en mm) Aplicación de doble capa cuando h ≥ 0.20 m: Capa inferior (principal): As_flex + As_retracción/2 Capa superior (retracción): As_retracción/2 Separación máxima entre barras: s_max = min(3·h, 450 mm) (NSR-10 C.7.6.5)

10. Momento de Diseño (para verificación de resistencia)

Carga última amplificada equivalente: wu_eq = (wu1·L1 + wu2·L2) / (L1 + L2) [kN/m] Momento de diseño (viga simplemente apoyada): Mu = wu_eq · L² / 8 [kN·m] Capacidad de diseño (sección rectangular, igual que vigas): a = As_inf · fy / (0.85·fc·b) φMn = 0.90 · As_inf · fy · (d - a/2) · 10⁻⁶ [kN·m] C/D_flexión = φMn / Mu

11. Criterio de Cumplimiento

Flexión: C/D = φMn / Mu ≥ 0.9 Deflexión inmediata: δ_inm ≤ L/360 Deflexión LP: δ_LP ≤ L/480 (con elem. susceptibles) δ_LP ≤ L/240 (sin elem. susceptibles) Refuerzo superior: As_sup_prov ≥ 0.9 × As_sup_req
ARCO considera adecuada una escalera cuando C/D ≥ 0.9 en flexión y cuando las deflexiones están dentro de los límites de servicio. Un C/D entre 0.9 y 1.0 indica que el refuerzo colocado es apto para la demanda de flexión calculada. Las deflexiones se verifican bajo cargas de servicio (sin factores de amplificación).
Verde — C/D ≥ 1.0 y δ ≤ límiteCumple. La escalera tiene reserva de resistencia y deflexiones aceptables.
Naranja — C/D ≥ 0.9 o δ cerca del límiteCumple — Adecuado. La escalera es apta. No requiere modificación.
Rojo — C/D < 0.9 o δ > límiteNo cumple. Revisar espesor, refuerzo o configuración de tramos.
