1. Esfuerzos Admisibles en el Concreto

ARCO verifica la pila bajo cinco categorías de combinaciones de carga, cada una con su propio límite de esfuerzo admisible en la sección de concreto:

Ag = área bruta de la sección (π·Df²/4 para maciza, o π·(Df²-Di²)/4 para hueca) Check1 — Gravitacionales servicio (D+L): C/D₁ = 0.25·fc·Ag·1000 / Ps_est_max ≥ 0.9 Check2 — Sísmicas servicio (D+L+E servicio): C/D₂ = 0.33·fc·Ag·1000 / Ps_din_max ≥ 0.9 Check3 — Gravitacionales diseño (amplificadas): C/D₃ = 0.35·fc·Ag·1000 / Pu_est_max ≥ 0.9 Check4 — Sísmicas diseño (amplificadas con sismo): C/D₄ = 0.35·fc·Ag·1000 / Pu_din_max ≥ 0.9 Check5 — Tracción: C/D₅ = 0.9·fy·As·N / P_traccion_max ≥ 0.9 (N = número de barras longitudinales, As = área de cada barra)
Los factores 0.25, 0.33 y 0.35 reflejan el uso de pilotes como elementos de cimentación sujetos a confinamiento lateral del suelo, lo que permite esfuerzos mayores que para columnas aisladas (NSR-10 C.15).

2. Capacidad de Carga del Suelo

Área de la punta: Ag_C = π·Dc²/4 si hay capitel (Dc > Df) Ag_C = π·Df²/4 si no hay capitel Q_punta = σ_adm · Ag_C [kN] Q_fricción = τ_fricción · π · Df · L [kN] Q_total = Q_punta + Q_fricción [kN] C/D_suelo = Q_total / Ps_max ≥ 0.9 (Ps_max = carga axial máxima de servicio)

3. Diagrama de Interacción Circular

3.1 Construcción del DI

El diagrama de interacción para sección circular se construye variando la posición del eje neutro c desde D (compresión pura) hasta ~0.04·D (cerca de tensión pura):

Para cada posición c: Área comprimida de la sección circular: Acc = A_segmento_circular(c, D) [m²] (integral geométrica del segmento circular de profundidad c) Para cada barra i (distribuidas uniformemente en circunferencia): dᵢ = posición desde fibra comprimida εᵢ = (c - dᵢ) / c × 0.003 fᵢ = max(-fy, min(fy, Es·εᵢ)) Pn = 0.85·fc·Acc·1000 + Σ(Asi·fᵢ) [kN] Mn = 0.85·fc·Acc·1000·e_cc + Σ(Asi·fᵢ·(D/2 - dᵢ)) [kN·m] (e_cc = excentricidad del centroide del área comprimida desde el centroide de la sección)

3.2 Factor de reducción φ

Para columnas con espiral: φ₀ = 0.75 Para columnas con estribos: φ₀ = 0.65 Transición igual que columnas rectangulares: φ = φ₀ si ε_t ≤ ε_y φ = interpolación lineal si ε_y < ε_t < 0.005 φ = 0.90 si ε_t ≥ 0.005

3.3 Verificación de demanda

Método 1 — Diagonal (distancia en plano P-M): Desde el origen, se traza una línea hacia el punto de demanda (Pu, Mu). La línea intersecta la envolvente φP-φM en el punto (Pc, Mc). Factor_DI = distancia(Pu,Mu) / distancia(Pc,Mc) C/D = 1 / Factor_DI Método 2 — Corte horizontal (φMn a nivel de Pu): φMn_Pu = InterpolarMnEnPu(DiagramaCircular, Pu) C/D = φMn_Pu / Mu ≥ 0.9

4. Cortante

NSR-10 C.11.3 y C.11.4

4.1 Área efectiva de cortante

Ae = 0.8 · D² [m²] (área efectiva de la sección circular para cortante)

4.2 Resistencia del concreto al cortante

Fórmula C.11-3 (sin carga axial): Vc0 = 0.17 · 0.75 · √fc · Ag · 1000 [kN] Fórmula C.11-4 (con carga axial Nu): Vc1 = 0.17 · 0.75 · (1 + Nu/(14000·Ag)) · √fc · Ae · 1000 [kN] (Nu en kN, Ag en m², fc en MPa; Nu positivo en compresión) Vc = min(Vc0, Vc1) [kN]

4.3 Resistencia del refuerzo transversal

Para espiral continua con paso p: Vs = 0.75 · 2 · Ass · fy · (0.8·D) / (s · 1000) [kN] Ass = área de la barra de la espiral [mm²] s = paso de la espiral [m] 0.8·D = brazo de momento de cortante (aprox.) Para estribos discretos: Vs = 0.75 · n · Ass · fy · (0.8·D) / (s · 1000) [kN] n = número de ramas eficaces

4.4 Resistencia total y verificación

φVn = Vc + Vs [kN] (el φ ya está incluido en Vc y Vs) Factor_V = φVn / Vu_max ≥ 0.9

5. Criterio de Cumplimiento Global

La pila se considera adecuada cuando TODOS los factores son ≥ 0.9: C/D₁ = 0.25·fc·Ag / Ps_est ≥ 0.9 (gravitacional servicio) C/D₂ = 0.33·fc·Ag / Ps_din ≥ 0.9 (sísmico servicio) C/D₃ = 0.35·fc·Ag / Pu_est ≥ 0.9 (gravitacional diseño) C/D₄ = 0.35·fc·Ag / Pu_din ≥ 0.9 (sísmico diseño) C/D₅ = 0.9·fy·As·N / P_tracción ≥ 0.9 (tracción) C/D_suelo = Q_total / P_servicio ≥ 0.9 C/D_DI = dist_cap / dist_demanda ≥ 0.9 (diagrama interacción) C/D_V = φVn / Vu ≥ 0.9 (cortante)
ARCO considera adecuada una pila cuando C/D ≥ 0.9 en todas sus verificaciones. Un C/D entre 0.9 y 1.0 indica que la pila es apta para las demandas calculadas. No es necesario modificar dimensiones ni refuerzo.
Verde — C/D ≥ 1.0Cumple. La pila tiene reserva en todos los estados de verificación.
Naranja — 0.9 ≤ C/D < 1.0Cumple — Adecuado. La pila es apta. No requiere modificación.
Rojo — C/D < 0.9No cumple. Revisar diámetro, longitud, refuerzo o parámetros del suelo.
