1. Diagrama de Interacción P-M (2D)

1.1 Metodología general

El diagrama de interacción se construye por compatibilidad de deformaciones, variando la profundidad del eje neutro c desde compresión pura (c → ∞) hasta tensión pura (c → 0). Para cada valor de c se calcula el par (φP, φM) correspondiente.

1.2 Deformaciones en el acero

ε_u = 0.003 (deformación unitaria máxima en la fibra extrema comprimida) Para cada barra i a distancia dᵢ desde la fibra comprimida extrema: εᵢ = (c - dᵢ) / c × ε_u Esfuerzo en la barra: fᵢ = Es · εᵢ si |εᵢ| < ε_y = fy/Es fᵢ = +fy si εᵢ ≥ ε_y (barra comprimida y fluye) fᵢ = -fy si εᵢ ≤ -ε_y (barra en tensión y fluye)

1.3 Bloque de compresión del concreto

a = β₁ · c β₁ = 0.85 si fc ≤ 28 MPa β₁ = 0.85 - 0.05·(fc - 28)/7 si fc > 28 MPa (mínimo 0.65) Fuerza del bloque: Cc = 0.85 · fc · a · b [kN] (fc en MPa, a y b en m) Momento del bloque respecto al centroide: Mc = Cc · (yc - a/2) donde yc es la distancia al centroide de la sección

1.4 Fuerza y momento resultantes nominales

Pn = Cc + ΣAsi·fᵢ [kN] (positivo = compresión) Mn = |Mc + ΣAsi·fᵢ·(yc - dᵢ)| [kN·m]

1.5 Factor de reducción φ variable

NSR-10 C.21.2.2
Deformación en la fibra más lejana en tensión: ε_t = (d_max - c) / c × ε_u donde d_max = distancia a la barra más alejada Si ε_t ≤ ε_y: φ = 0.65 (sección controlada por compresión) Si ε_y < ε_t < 0.005: φ = 0.65 + (ε_t - ε_y) / (0.005 - ε_y) × (0.90 - 0.65) (transición lineal) Si ε_t ≥ 0.005: φ = 0.90 (sección controlada por tensión)

1.6 Capacidades de diseño

φPn = φ · Pn [kN] φMn = φ · Mn [kN·m]

1.7 Límite de compresión pura

NSR-10 C.22.4.2
φPn_max = 0.80 · φ₀ · [0.85·fc·(Ag - Ast) + fy·Ast] (para estribos) φPn_max = 0.85 · φ₀ · [0.85·fc·(Ag - Ast) + fy·Ast] (para espiral) φ₀ = 0.65 (estribos), 0.75 (espiral)

1.8 Distribución de barras

ARCO usa la función DistribuirBarrasConEsquinas que garantiza 4 barras en las esquinas de la sección rectangular más barras intermedias distribuidas proporcionalmente en cada cara, según el número total ingresado por el usuario.

2. Flexo-compresión Biaxial — Criterio de Bresler

2.1 Capacidades uniaxiales a nivel de Pu

Para cada combinación de diseño, ARCO interpola la capacidad en cada eje a nivel de la carga axial Pu:

φMn3(Pu) = InterpolarMnEnPu(ListaDI_eje3, Pu) [kN·m] φMn2(Pu) = InterpolarMnEnPu(ListaDI_eje2, Pu) [kN·m] La interpolación es lineal entre los puntos adyacentes del DI que rodean a Pu.

2.2 Criterio de Bresler lineal

F_Interaccion = Mu3 / φMn3(Pu) + Mu2 / φMn2(Pu) - 1.0 Interpretación: F_Interaccion < 0 → cumple también como uniaxial (raramente ocurre) 0 ≤ F_Interaccion < 1 → cumple (D/C < 1) F_Interaccion ≥ 1 → no cumple (D/C ≥ 1) C/D = 1 / F_Interaccion (lo que muestra ARCO al usuario)
Internamente, ARCO almacena F_Interaccion como D/C (demanda sobre capacidad). Al mostrar resultados al usuario, siempre invierte: C/D = 1/F_Interaccion. Un C/D ≥ 1.0 significa que cumple.

3. Superficie Biaxial 3D

3.1 Construcción de la superficie

Para el formulario DI 3D, se construye la superficie φMn(P, θ) variando el ángulo θ del eje neutro de 0° a 360° en incrementos de 5° o 10°. Para cada ángulo θ y nivel de P:

  • El eje neutro se orienta en la dirección θ respecto al eje de la sección.
  • Se calcula el DI en esa dirección por el mismo método de compatibilidad de deformaciones.
  • El par (φMn3, φMn2) a nivel de P forma un punto en la superficie.

3.2 Criterio elíptico de colorización

DC_e = √((Mu3/φMn3(Pu))² + (Mu2/φMn2(Pu))²) Interpretación geométrica: DC_e es la relación entre la distancia del punto de demanda al origen y la distancia de la superficie al origen, medida en la dirección del eje que une origen con el punto de demanda en el plano M3-M2. Colores: DC_e ≤ 1.0 → Verde (cumple) 1.0 < DC_e ≤ 1.1 → Naranja (10% de tolerancia) DC_e > 1.1 → Rojo (no cumple)

4. Criterio de Cumplimiento

C/D = 1 / F_Interaccion_Bresler Combo gobernante: combinación que produce el menor C/D (mayor D/C)
ARCO considera adecuada una columna cuando C/D ≥ 0.9. Un C/D entre 0.9 y 1.0 significa que la columna con el refuerzo colocado es apta para soportar la demanda de flexo-compresión biaxial calculada. No requiere modificación.
Verde — C/D ≥ 1.0Cumple. La columna tiene reserva de resistencia biaxial.
Naranja — 0.9 ≤ C/D < 1.0Cumple — Adecuado. La columna es apta para la demanda. No requiere modificación.
Rojo — C/D < 0.9No cumple. Revisar refuerzo longitudinal o dimensiones de sección.
