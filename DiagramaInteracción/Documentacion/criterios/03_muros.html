1. Flexo-compresión

El análisis de flexo-compresión en muros sigue la misma metodología de compatibilidad de deformaciones que las columnas, aplicado a la sección transversal del muro (incluyendo alma y elementos de borde).

1.1 Diagrama de Interacción del Muro

Para cada posición del eje neutro c (varía de 0 a Lw): ε_u = 0.003 en la fibra comprimida extrema Para cada barra i del refuerzo vertical distribuido y EB: εᵢ = (c - xᵢ) / c × ε_u (xᵢ = posición desde fibra comprimida) fᵢ = max(-fy, min(fy, Es·εᵢ)) Cc = 0.85 · fc · tw · min(a, Lw) con a = β₁·c [kN] Pn = Cc + Σ(Asi·fᵢ) [kN] Mn = Cc·(Lw/2 - a/2) + Σ(Asi·fᵢ·(Lw/2 - xᵢ)) [kN·m]

1.2 Factor de reducción φ

Igual que columnas: φ = 0.65 para compresión controlada, transición lineal hasta φ = 0.90 para tensión controlada (ε_t ≥ 0.005).

1.3 Verificación de demanda

Para cada combinación de diseño: Pu, Mu (del análisis ETABS, Pier Forces) Factor_Demanda_Flexo = DI_Bresler (similar a columnas) C/D = 1 / Factor_Demanda_Flexo ≥ 0.9 para cumplir

2. Cortante

NSR-10 C.11.9 y C.21.9.4

2.1 Límite de esfuerzo para cuantías mínimas

V_lim = 0.083 · tw · Lw · √fc · 1000 [kN] (tw y Lw en m, fc en MPa) Si Vu ≤ V_lim: ρh_min = 0.0012 (0.12%) ρv_min = 0.0020 (0.20%) Si Vu > V_lim: ρh_min = 0.0025 (0.25%) ρv_min = 0.0025 (0.25%)

2.2 Resistencia al cortante

Vc = 0.75 · 0.17 · tw · Lw · √fc · 1000 [kN] Vs = 0.75 · tw · Lw · ρh · fy · 1000 [kN] φVn = Vc + Vs [kN] C/D_cortante = φVn / Vu ≥ 0.9 para cumplir
En la fórmula de Vc, el factor 0.75 es el φ de cortante y ya está incluido. En ARCO, Vc y Vs se calculan directamente como φ×capacidad nominal para simplificar la presentación.

2.3 Vu de diseño

El cortante de diseño Vu se toma como el máximo valor absoluto entre todas las combinaciones de diseño seleccionadas:

sec.Vu = combsD.Max(Function(c) Math.Abs(c.V2)) Este cálculo se realiza en Obtencion_Macroparametros(), después de seleccionar las combinaciones de diseño.

3. Elementos de Borde

NSR-10 C.21.9.6

3.1 Criterio de esfuerzo máximo

Esfuerzo máximo en la fibra comprimida: σ_max = Pu/(Ag) + Mu·(Lw/2) / Ig [MPa] Límite según nivel de ductilidad: Para DUO: σ_adm = 0.2·fc Para DMO: σ_adm = 0.3·fc Si σ_max > σ_adm / 0.9 → Requiere elemento de borde especial

3.2 Longitud requerida del elemento de borde

c = profundidad del eje neutro bajo las cargas máximas de compresión L_EB_req = max(c - 0.1·Lw, c/2) [m] Verificación de longitud provista: L_EB_prov ≥ L_EB_req × 0.9 (factor de tolerancia)

3.3 Criterio de deformación (eje neutro)

Límite de profundidad del eje neutro: C_lim = Lw / (600 · (Du/Hw)) Derivas mínimas consideradas: DUO: du_hw_min = 0.0075 DMO: du_hw_min = 0.0035 (Se toma el mayor de du/hw_real y du_hw_min) Si C ≤ C_lim / 0.9 → No requiere EB por deformación (cumple) Si C > C_lim / 0.9 → Requiere EB especial por deformación

4. Criterio de Cumplimiento General

Para que el muro sea adecuado, todos los factores deben ser ≥ 0.9: C/D_flexión = (C/D Bresler) ≥ 0.9 C/D_cortante = φVn / Vu ≥ 0.9 L_EB_prov / L_EB_req ≥ 0.9 (si requiere EB especial)
ARCO considera adecuado un muro cuando C/D ≥ 0.9 en todos sus estados de verificación. Un C/D entre 0.9 y 1.0 indica que el muro con el refuerzo colocado es apto para las demandas de flexo-compresión, cortante y elementos de borde. No requiere modificación.
Verde — C/D ≥ 1.0Cumple. El muro tiene reserva de resistencia.
Naranja — 0.9 ≤ C/D < 1.0Cumple — Adecuado. El muro es apto para la demanda. No requiere modificación.
Rojo — C/D < 0.9No cumple. Revisar refuerzo distribuido, elementos de borde o espesor del muro.

6. Refuerzo del Elemento de Borde

NSR-10 C.21.9.6.4

El elemento de borde especial requiere:

  • Cuantía mínima de refuerzo longitudinal: ρ_EB ≥ 0.005 (0.5%)
  • Refuerzo transversal de confinamiento (igual que columnas en zona de articulación plástica): estribos cerrados o espiral
  • Separación de estribos en EB: s ≤ min(b_EB/4, 150 mm, 6·Ø_barra_long)
  • Extensión vertical del EB: al menos hw/6, Lw, o lu/16 por encima y debajo del nivel donde se requiere
