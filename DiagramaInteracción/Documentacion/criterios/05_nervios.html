1. Ancho Efectivo de la Sección T

NSR-10 C.8.10.2
ln = L_total - b_apoyo_I/2 - b_apoyo_D/2 (luz libre entre caras de apoyos) sw = paso - bw (claro libre entre almas adyacentes) Vuelo de ala a cada lado del alma: vola = min(8·tf, sw/2, ln/8) Ancho efectivo T: be = bw + 2·vola [mm o m]
El ancho efectivo be solo aplica para momentos positivos (zona de vano, eje neutro en la loseta). Para momentos negativos (sobre apoyos), se usa solo el alma bw.

2. Cara de Apoyo — Interpolación de Fuerzas

Las fuerzas de diseño se toman en la cara del apoyo, no en el eje. ARCO interpola linealmente:

Posición de cara del apoyo izquierdo: x_cara_I = b_apoyo_I / 2 Posición de cara del apoyo derecho: x_cara_D = L_total - b_apoyo_D / 2 Interpolación lineal entre las dos estaciones ETABS más cercanas a x_cara: M_cara = M_est1 + (M_est2 - M_est1) × (x_cara - x_est1) / (x_est2 - x_est1) V_cara = V_est1 + (V_est2 - V_est1) × (x_cara - x_est1) / (x_est2 - x_est1)

3. Peralte Efectivo

d = h - recubrimiento - Ø_estribo - Ø_barra_long/2 [mm] h = altura total del nervio (loseta + nervio)

4. Flexión Negativa — Sección Rectangular bw

Para momentos negativos (cara de apoyo), el eje neutro está en el alma:

4.1 Cuantía mínima

NSR-10 C.9.6.1.2
ρ_min = max(1.4/fy, 0.25·√fc/fy) As_min_neg = ρ_min · bw · d [mm²]

4.2 Capacidad de diseño

a = As_prov · fy / (0.85·fc·bw) [mm] φMn_neg = 0.90 · As_prov · fy · (d - a/2) · 10⁻⁶ [kN·m] C/D_neg = φMn_neg / Mu_neg ≥ 0.9

5. Flexión Positiva — Sección T con be

Para momentos positivos (zona de vano), el eje neutro puede estar en la loseta o en el alma:

5.1 Verificar posición del eje neutro

Paso 1: Suponer eje neutro en la loseta (a ≤ tf): a_ala = As_prov · fy / (0.85·fc·be) [mm] Paso 2: Verificar: Si a_ala ≤ tf → eje neutro en loseta → usar sección rectangular con b = be Si a_ala > tf → eje neutro en alma → usar método de dos bloques

5.2 Eje neutro en la loseta (caso frecuente)

φMn_pos = 0.90 · As_prov · fy · (d - a_ala/2) · 10⁻⁶ [kN·m] C/D_pos = φMn_pos / Mu_pos ≥ 0.9

5.3 Eje neutro en el alma (caso T real)

Fuerza del ala comprimida (parte fuera del alma): Cf = 0.85·fc·(be - bw)·tf [kN] Fuerza del alma comprimida: Cw = As·fy - Cf [kN] (asumiendo As a plena fluencia en tensión) Profundidad del bloque en el alma: a_alma = Cw / (0.85·fc·bw) [mm] Momento: φMn_T = 0.90 · [Cf·(d - tf/2) + Cw·(d - tf - a_alma/2)] · 10⁻⁶ [kN·m]

6. Cortante

NSR-10 C.22.5.5.1 y C.13.3.5

6.1 Factor de incremento para nervios

factor_nervio = 1.1 si paso ≤ 750 mm (NSR-10 C.13.3.5) factor_nervio = 1.0 si paso > 750 mm

6.2 Resistencia del concreto

Vc = factor_nervio · 0.17 · √fc · bw · d · 1000 [kN] (fc en MPa, bw y d en m)

6.3 Resistencia del refuerzo transversal

Vs = Av · fy · d / (s · 1000) [kN] Av = n_ramas · área_barra_estribo [mm²] s = separación de estribos [m]

6.4 Resistencia total

φVn = 0.75 · (Vc + Vs) [kN] C/D_cort = φVn / Vu ≥ 0.9

7. Criterio de Cumplimiento

El nervio se considera adecuado cuando: C/D_neg_I = φMn_sup_I / Mu_neg_I ≥ 0.9 C/D_pos_C = φMn_inf_C / Mu_pos_C ≥ 0.9 C/D_neg_D = φMn_sup_D / Mu_neg_D ≥ 0.9 C/D_cort_I = φVn_I / Vu_I ≥ 0.9 C/D_cort_D = φVn_D / Vu_D ≥ 0.9 Penalización si As_prov < As_min: C/D se penaliza proporcionalmente, puede ser < 0.9 aunque φMn > Mu
ARCO considera adecuado un nervio cuando C/D ≥ 0.9 en todas sus zonas de verificación. Un C/D entre 0.9 y 1.0 significa que el nervio con el refuerzo colocado es apto para las demandas de flexión y cortante. No requiere modificación del refuerzo.
Verde — C/D ≥ 1.0Cumple. El nervio tiene reserva de resistencia.
Naranja — 0.9 ≤ C/D < 1.0Cumple — Adecuado. El nervio es apto. No requiere modificación.
Rojo — C/D < 0.9No cumple. Revisar refuerzo o geometría de la sección nervada.
